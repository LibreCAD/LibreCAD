Importation et ouverture de dessins dans LibreCAD

LibreCAD est une application autonome

Vous pouvez ouvrir les types de fichiers suivants dans l’application autonome LibreCAD :

  • Drawing Exchange/AutoCAD (*.dxf; *.dwg)
  • LibreCAD Font (*.lff)
  • QCad Font (*.cxf)
  • Jww (*.jww)

Importation des dessins à partir de ProNest

Tout type de fichier pouvant être importé dans ProNest peut être ouvert dans LibreCAD pour effectuer un nettoyage de CAO, soit avant ou après l’importation de la pièce dans ProNest.
