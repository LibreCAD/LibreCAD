## Third-party notices of the MSIX package ##

This file is part of the Microsoft Store (MSIX) package of LibreCAD only.
It adds to `readme.md` the notices of the fonts and libraries in the
package that `readme.md` does not name. The licence texts it refers to are
in the same folder.

### Qt ###

The package includes the Qt libraries. Qt offers them under the LGPLv3,
the GPLv2 and the GPLv3; LibreCAD, which is licensed under the GPLv2
only, uses them under the GPLv2 (`gpl-2.0.txt`). The Qt libraries contain
third-party code under its own licenses; `qt-third-party.txt` lists each
component with its copyright and license text. `SOURCE.txt` says where
the source code of LibreCAD and of these libraries can be found.

- <https://www.qt.io/download-open-source>
- <https://doc.qt.io/qt-6/licenses-used-in-qt.html>
